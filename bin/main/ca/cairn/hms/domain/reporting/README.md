# Sous-domaine : Rapports (`domain.reporting`)

**Type :** support

Rapports produits par les administrateurs.

- **Rapport d'utilisation d'un sentier :** pour un sentier et une période (début, fin), nombre de randonnées, nombre de participants et nombre de randonnées annulées.
- **Conception :** lecture seule sur les données de `hike` et de `signup`.
- **Cas d'utilisation :** Générer un rapport d'utilisation des sentiers.
