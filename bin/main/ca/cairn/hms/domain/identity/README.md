# Sous-domaine : Identité et accès (`domain.identity`)

**Type :** générique

Authentification et autorisation des utilisateurs.

- **Rôles :** visiteur (sans compte), randonneur, organisateur de randonnée, administrateur.
- **Règles clés :** toute fonctionnalité autre que la consultation des randonnées ouvertes exige une authentification et une autorisation ; les informations sur les randonneurs sont stockées de façon sécuritaire (chiffrement).
- **Cas d'utilisation :** Se connecter, Se déconnecter.
