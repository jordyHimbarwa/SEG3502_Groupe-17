# Sous-domaine : Sentiers (`domain.trail`)

**Type :** support (données externes)

Sentiers de la CCN sur lesquels le club organise ses randonnées. Le club ne tient pas lui-même d'informations sur les sentiers.

- **Source :** jeu de données des sentiers publié par la CCN (ArcGIS Hub).
- **Concepts :** sentier (nom, type, surface, difficulté, saison d'ouverture, secteur et zone, stationnement, tracé et emplacement / point de départ).
- **Règles clés :** seuls les sentiers où la randonnée est permise sont utilisables.
- **Conception :** une couche anticorruption traduit le modèle de la CCN ; une copie locale permet au système de continuer à fonctionner si la CCN est indisponible.
