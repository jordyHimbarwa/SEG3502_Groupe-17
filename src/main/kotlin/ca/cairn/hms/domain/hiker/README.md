# Sous-domaine : Randonneurs et adhésions (`domain.hiker`)

**Type :** support

Profil des membres du club qui utilisent le système.

- **Concepts :** randonneur (identifié de façon unique par son courriel), coordonnées, date de naissance, personne-ressource en cas d'urgence, niveau d'habileté, adhésion (active, expirée, suspendue), code d'invitation, décharge de responsabilité (acceptée par un tuteur légal si moins de 18 ans), certification de chef de randonnée (numéro, dates de délivrance et d'expiration) et niveau d'organisateur.
- **Règles clés :** l'enregistrement exige un code d'invitation valide ; un organisateur est un randonneur à qui un administrateur a enregistré une certification.
- **Hors portée :** gestion des ressources humaines du club, dont l'émission des codes d'invitation et le processus d'adhésion.
