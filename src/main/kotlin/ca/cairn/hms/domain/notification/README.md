# Sous-domaine : Notifications (`domain.notification`)

**Type :** générique

Communications envoyées aux randonneurs.

- **Courriels :** confirmation d'inscription, position en liste d'attente, promotion depuis la liste d'attente, annulation d'une randonnée (avec motif), rappel la veille de la randonnée.
- **Météo :** prévisions au point de départ obtenues d'un service externe ; un avertissement est ajouté au rappel si de la pluie ou de la neige est prévue.
- **Dégradation :** si les prévisions ne peuvent pas être obtenues, le rappel est envoyé sans avertissement.
